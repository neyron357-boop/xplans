# XPlans

Личный штаб на телефоне: линии к цели, запасные пути, козыри и память. Сделано по дизайну XPlans (тема «Ночь»).

**Открыть:** https://neyron357-boop.github.io/xplans/

Поставить как приложение:

- **iPhone** — открыть в Safari → «Поделиться» → «На экран „Домой“».
- **Android** — открыть в Chrome → ⋮ → «Установить приложение» (или «Добавить на гл. экран»).

Разделы:

- **Сегодня** — «Сколько сил?», потом «Что изменилось?», шаг дня под твои силы, корешки.
- **Корни** — древо линий (строится из твоих данных), «Что если» с готовностью к рискам, рукав с запасом и козырями.
- **Рост** — привычки: корешок уходит глубже с каждым днём подряд; знание: что учишь, к чему ведёт, контрольная раз в месяц (английский на слух — волной).
- **Память** — годовые кольца, арки, связи между событиями.
- **Я** — узоры из твоих дней (считаются на телефоне, пока данных мало — честно ждут) и кодекс: свои правила и пауза на 90 секунд, когда задели.

## Где данные

Только на телефоне: IndexedDB браузера плюс копия в localStorage. На сервер ничего не уходит.
Раз в неделю делай копию: «Память» → «Копия» → «Сохранить копию» (файл можно отправить себе в Telegram или сохранить в Файлы). Тем же экраном копия загружается обратно.

Каждый ответ дня (силы, что изменилось, шаг, корешки и время отметки) сохраняется — из этих сигналов растут «Узоры».

## Команды

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # сборка в dist/
npm run preview   # проверить сборку, http://localhost:4173
npm run phone     # открыть с телефона в той же Wi-Fi сети
npm run icons     # перерисовать иконки из scripts/icons.mjs
```

## Как устроено

- `src/store` — модель данных, сохранение, действия, стартовый план (`seed.ts`).
- `src/lib/roots.ts` — раскладка корней: каждая линия — кривая Безье от семени к цели, запасные запасных ответвляются от родителя.
- `src/lib/rings.ts` — годовые кольца памяти.
- `src/lib/growth.ts` — серии корешков, обычное время отметки, форма корешка.
- `src/lib/patterns.ts` — узоры из дневных ответов и раскладка «ткани дней».
- `src/screens`, `src/sheets`, `src/ui` — экраны, нижние листы и общие компоненты.
- `vite.config.ts` пишет `sw.js`, который кэширует всё приложение: после первого открытия оно работает без сети.
- `.github/workflows/pages.yml` выкладывает сборку на GitHub Pages при каждом push в `main`.
